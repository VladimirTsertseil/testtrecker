# 116 дней — PWA

Версия программы: 01-09-2026.

## Что где лежит
- `program.js` — единственный файл с программами A/B/C. Для изменения прогрессии меняйте его.
- `index.html` — интерфейс.
- `app.js` — логика, локальное сохранение и история.
- `manifest.webmanifest`, `sw.js`, иконки — установка на iPhone и офлайн-режим.

## GitHub Pages
1. Создайте публичный репозиторий, например `tracker-116`.
2. Загрузите содержимое этой папки в корень репозитория.
3. Settings → Pages → Deploy from a branch → `main` / root.
4. Откройте выданный HTTPS-адрес в Safari на iPhone.
5. Share → Add to Home Screen.

## Обновление программы
Изменяйте только `program.js`. При смене `version` текущая незавершённая сессия будет сброшена, а история завершённых тренировок сохранится.

Важно: история хранится локально в браузере/PWA на конкретном устройстве. Итоговые сводки лучше также отправлять в ChatGPT как резервную копию.
